Antenna Designer

An interactive playground for amateur-radio antennas. Dial in the physical dimensions on the left and watch the radiation patterns, impedance and SWR redraw live on the right — alongside a to-scale 3D view of the antenna.

📡 Start the Designer View on GitHub

Design, Then Watch It Radiate

Antenna Designer models a broad set of common ham-radio antennas with parametric physics. Pick a type, adjust element counts, spacing, diameters, heights and feed systems, and the app recomputes gain, front-to-back ratio, feedpoint impedance and bandwidth in real time. The models are simplified approximations built for exploration and intuition — great for understanding why an antenna behaves the way it does before you confirm a final design in a full-wave solver like NEC / 4nec2.

What You'll See

🎯

Azimuth pattern

Polar horizontal radiation plot, 0 dB outer ring down to −40 dB, forward direction to the right.

📐

Elevation pattern

Vertical-plane plot with ground-reflection lobes and real-ground takeoff angles.

📈

Impedance & SWR

Swept SWR, resistance and reactance vs frequency, with a 2:1 reference line.

🧊

3D geometry

An interactive, to-scale drawing of the antenna. Orbit, pan, zoom and reset.
